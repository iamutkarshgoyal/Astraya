# Product Asset Staging

Use this folder for named web campaign copies and incoming product photography.
Production catalog files must also be exported to
`images/products/<product-slug>/` so the existing API and jsDelivr URLs
continue to work.

Current additions:

- `heartglow-gel-soy-mini-jar-candle/`: eight colour views in JPEG and AVIF
- `hero/`: square product thumbnails for the interactive homepage rail
